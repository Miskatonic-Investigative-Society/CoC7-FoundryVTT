# Folha de comandos rapidos

## Regras gerais

A maioria dos componentes da ficha pode ser clicada para acionar um teste/rolagem.
Como regra geral, voce pode modificar esses pedidos:

- `Shift` avancara rapidamente o pedido.
- `Ctrl` [apenas GM] criara no chat um link com esse pedido de rolagem para os jogadores.

## Sanidade

| Comando                            | Acao                                                     |
| ---------------------------------- | -------------------------------------------------------- |
| `Ctrl+Shift` + _clique esquerdo SAN_    | Solicita um Teste de Sanidade para o personagem          |
| `Ctr+Shift+Alt` + _clique esquerdo SAN_ | Solicita um Teste de Sanidade e define a perda de sanidade |

## Rolagens combinadas / opostas

| Comando                             | Acao                                                 |
| ----------------------------------- | ---------------------------------------------------- |
| _Clique direito em um elemento_     | Inicia/inclui a rolagem em uma rolagem **oposta**    |
| `Alt` + _Clique direito em um elemento_ | Inicia/inclui a rolagem em uma rolagem **combinada** |

## Outros

| Comando | Acao                            |
| ------- | ------------------------------- |
| `c`     | Mostra a ficha do _meu proprio_ personagem |
